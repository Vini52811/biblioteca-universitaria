# Biblioteca Universitária

Projeto de refatoração de banco de dados para uma biblioteca universitária.

## Tema 12

O projeto busca resolver problemas de redundância na tabela Emprestimos, separando as informações dos livros e criando um índice para melhorar as consultas pela data de devolução.

## Objetivos
- Organizar as tabelas do banco de dados.
- Evitar dados duplicados.
- Utilizar chaves primárias e estrangeiras.
- Criar índices para melhorar o desempenho.

## Organização do projeto

O banco de dados foi dividido em tabelas relacionadas para evitar
duplicidade de informações.

Foram criados scripts para:
- Estrutura das tabelas e relacionamentos.
- Inserção de dados para testes.
- Consultas SQL para análise dos empréstimos.
